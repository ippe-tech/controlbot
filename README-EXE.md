# Сборка ControlBot.exe и Helper24Sync.exe

PyInstaller не умеет кросс-сборку: Windows-exe собирается **на Windows**.
Здесь готовый комплект — один запуск, и в папке `release\` появятся два exe.

## Что получится

| Файл | Что это |
|---|---|
| `release\ControlBot.exe` | сам бот: мониторинг, активность, команды, `.env` рядом |
| `release\Helper24Sync.exe` | передача активности ПК в Helper24 (без консоли, лог в `helper24_sync.log`) |

## Как собрать

1. Нужен Python 3.10+ (галочка «Add python.exe to PATH»).
2. Запустить `Собрать-EXE.bat` — он сам создаст `.venv-build`, поставит
   зависимости и PyInstaller, соберёт оба exe.
3. Готовые файлы — в `release\`.

Первый запуск долгий (5–10 минут): PyInstaller распаковывает telegram, psutil, Pillow.

## Как запускать

```
release\
  ControlBot.exe
  Helper24Sync.exe
  .env              ← создаётся при первом запуске
```

### Первый запуск — мастер настройки

`ControlBot.exe` при старте сам спрашивает две вещи:

1. **Токен бота** от @BotFather (ввод скрыт, сразу проверяется через `getMe`);
2. **Название ПК** (по умолчанию — имя компьютера) и клуб/подразделение.

Дальше всё автоматически: создаётся `.env`, настраивается автозапуск при входе,
бот стартует. Повторно мастер не появится, пока в `.env` есть токен.

Флаги: `ControlBot.exe --setup` — пройти мастер заново, `--no-setup` — не спрашивать.

Если `ALLOWED_CHAT_IDS` пуст, бот работает в режиме настройки и по команде `/start`
покажет ваш chat_id — впишите его в `.env` и перезапустите.

Рабочие файлы создаются рядом с exe: `bot.log`, `activity_data.json`,
`controlbot_instance.lock`.

`Helper24Sync.exe` тоже читает `.env` из своей папки (ключи `HELPER24_*`),
файл активности — `activity_data.json` рядом.

## Автозапуск

- `ControlBot.exe` — задача планировщика «При входе» или ярлык в `shell:startup`.
- `Helper24Sync.exe` — то же самое; окна нет, смотреть `helper24_sync.log`.

## Частые проблемы

- **Антивирус/Defender** может ругаться на свежесобранный one-file exe
  (ложное срабатывание на распаковщик PyInstaller). Добавить в исключения.
- **«Не задан TELEGRAM_BOT_TOKEN»** — `.env` лежит не рядом с exe или назван
  `env.txt`.
- **Долгий старт 3–5 секунд** — нормально для one-file: распаковка во временную папку.
- Нужен файл поменьше и быстрее — собирайте без `--onefile` (папка `dist\ControlBot\`),
  в spec это `EXE(..., exclude_binaries=True)` + `COLLECT`.

## Если нужна сборка из другого bot.py

Положите свой `bot.py` в `src\` рядом с `activity_tracker.py` и `browser_sites.py`
(или поправьте путь в `build\controlbot.spec`) и запустите `.bat` снова.

## Отчёты в Helper24

Бот сам присылает срез работы ПК два раза в сутки — в **08:00** и **21:00**:
активные приложения, АФК, состояние системы, ошибки из лога. Помощник их
структурирует и присылает готовый отчёт владельцу в Telegram.

Отправка идёт по тому же защищённому каналу (ntfy + Fernet), что и у клубных
агентов; ключ по умолчанию уже прописан. Отключить можно, убрав
`HELPER24_FERNET_KEY` из `.env`.

## Автообновление

`ControlBot.exe` при старте и раз в сутки проверяет
`https://gym24server.online/controlbot/latest.json`. Если там версия новее —
скачивает новый exe, сверяет sha256, подменяет файл и перезапускается.
Ручная проверка — команда `/update` в боте.

Публикация новой версии — на сервере: `scripts/publish_update.sh <exe> <версия>`.

## Обновления через GitHub (без своего сервера)

Бот умеет брать обновления прямо из GitHub Releases — сервер `latest.json`
тогда не нужен.

1. Создайте репозиторий (можно приватный) и залейте в него папку проекта.
2. В `.env` укажите:
   ```
   UPDATE_SOURCE=github
   UPDATE_REPO=ваш-логин/controlbot
   # для приватного репозитория ещё токен с правом contents:read
   UPDATE_TOKEN=
   ```
3. Перед выпуском поднимите `APP_VERSION` в `src/bot.py`.
4. Поставьте тег и отправьте его:
   ```
   git tag v2026.11.04
   git push --tags
   ```
5. GitHub Actions (`.github/workflows/build-exe.yml`) соберёт exe на
   `windows-latest` и приложит его к релизу.
6. Установленные боты увидят новый релиз при старте, раз в сутки (10:17)
   или по команде `/update` — скачают, проверят sha256, подменят файл и
   перезапустятся.

Тот же workflow можно запустить вручную: Actions → Build ControlBot.exe → Run workflow.

Важно: версия в `APP_VERSION` должна совпадать с тегом (тег `v2026.11.04` →
`APP_VERSION = "2026.11.04"`), иначе бот не поймёт, что это новее.
